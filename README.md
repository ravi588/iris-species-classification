# iris-species-classification
Overview:  Objective: Predict species (Setosa, Versicolor, Virginica) based on sepal/petal dimensions.  Analysis: Used Seaborn for data visualization to identify species separation.  Models: Compared SVC, Logistic Regression, and Decision Trees.  Performance: Achieved a peak accuracy of 96.67%.  Tech Stack: Python, Scikit-Learn, Pandas, Seaborn.
