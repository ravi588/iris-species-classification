# Iris Flower Classification 🌸

A Machine Learning project to classify Iris flowers into three species (Setosa, Versicolor, and Virginica) based on sepal and petal measurements.

## 📊 Project Overview
This project explores the classic Iris dataset using Exploratory Data Analysis (EDA) and implements three different classification models to compare performance.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Seaborn, Matplotlib, Scikit-Learn

## 📈 Models Used & Results
| Model | Accuracy |
| :--- | :--- |
| Support Vector Machine (SVM) | 96.67% |
| Logistic Regression | 96.67% |
| Decision Tree | 93.33% |

## 🚀 How to Run
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`.
3. Open the Jupyter Notebook in the `notebooks/` folder.
